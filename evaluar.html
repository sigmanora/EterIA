Evaluar ayudantes

Registra las faltas de cada ayudante durante el semestre (recorrecciones, atrasos, reclamos) y la evaluación se calcula sola. Todo queda guardado en este navegador.

Evaluaciones a registrar

Agrega las evaluaciones que quieras registrar (ej. C1, C2, CREC, Control 3...). Cada una se convierte en una columna donde marcar las faltas de cada categoría. No hay una lista predeterminada: se guarda automáticamente lo que agregues.

Nota final: 4 si evaluación ≥ 95% 3 si evaluación ≥ 80% 2 si evaluación ≥ 70% (bajo el último umbral → Nota 1)
